Reai 使用文档

Reai Documentation

面向 32 位（armeabi-v7a）安卓手机的 AI 聊天客户端。本文讲清楚怎么装、怎么填接口、怎么开始用。

An AI chat client built for 32-bit (armeabi-v7a) Android phones. Install, configure a model provider, and start chatting.

1. 安装

1. Install

  1. 在 官网首页点“直接下载 APK”，或复制直链：https://github.com/ETQWFD/etc/releases/latest/download/etc-armv7.apk。
  2. 安装包只含 armeabi-v7a（32 位 ARM）原生库，最低需要 Android 8.0（API 26）。64 位手机一般也能兼容运行。
  3. 若提示“未知来源”，到系统设置里允许当前浏览器安装应用即可。
  4. 安装后建议对照首页公布的 SHA-256 校验值核对文件。
  1. Download from the homepage direct link: https://github.com/ETQWFD/etc/releases/latest/download/etc-armv7.apk.
  2. The APK contains armeabi-v7a (32-bit ARM) native libs only; Android 8.0 (API 26) or later is required. Most 64-bit phones can still run it.
  3. Allow your browser to install apps from unknown sources if prompted.

2. 配置模型服务商

2. Add a model provider

Reai 不内置任何模型，也不提供服务器。第一次打开，进入 设置 → 模型与服务 → 服务商，添加一个兼容 OpenAI 协议的接口。

接口地址 (Base URL)填到 /v1 这一层，例如 https://api.example.com/v1。
密钥 (API Key)填你在服务商后台生成的密钥。
模型 (Model)手动填入模型名，或在支持的服务上点“拉取模型列表”。

保存后回到 设置 → 默认模型，把默认对话、向量（搜索）等模型选上，就可以正常聊天了。

Reai ships with no model or server. Go to Settings → Providers, add an OpenAI-compatible endpoint (base URL ending with /v1, API key, model name), then pick it under Default model.

3. 创建助手

3. Assistants

助手页内置一个“默认助手”。点进助手可配置：

  • 基础设定：名称、头像、使用的模型和生成参数。
  • 提示词：系统提示、消息模板、正则规则。模板里的 {{char}}、{{model_name}} 等会在发送给模型时替换，助手卡片上看到的是渲染后的预览，不会把花括号发给你看。
  • 扩展管理 / 记忆 / 自定义请求 / MCP / 本地工具：按需开关。

Open the assistant page to edit name, avatar, model, system prompt, memory, MCP and local tools.

4. 开始对话

4. Chat

  • 支持文本、图片、PDF、Docx 等多模态输入（取决于所选模型）。
  • 回复支持代码高亮、表格、公式、Mermaid 图表。
  • 聊天记录可用中文关键词全文检索（内置 jieba 分词与拼音）。
  • 在 设置 → 数据 里可以备份、恢复或清理文件。
  • Send text, images, PDF or Docx depending on the model.
  • Rendered code blocks, tables, formulas and Mermaid diagrams are supported.

5. 功能说明

5. Features

  • 多服务商：自定义地址、密钥、模型，一套界面切换多个后端。
  • 语音：可接 TTS 服务朗读回复（设置 → 语音服务）。
  • 联网/工作区：工作区为可选功能，32 位设备如需容器环境要自行准备 armhf 的 rootfs。
  • 深色模式：跟随系统外观。
  • Multiple OpenAI-compatible providers, TTS, dark mode and optional workspace features.

6. 本地工具

6. Local tools

在助手详情的“本地工具”里，按两组管理：

  • 交互能力：JavaScript 引擎、时间信息、剪贴板、向你提问、文字转语音。
  • 设备与数据：屏幕使用时间、日历、图表展示。

屏幕时间需要“使用情况访问”权限，日历需要日历读写权限，开启时按提示授权即可。

Local tools are grouped into interaction (JS engine, time, clipboard, ask user, TTS) and device/data (screen time, calendar, chart). Grant the requested Android permissions when enabling them.

7. 常见问题

7. FAQ

打开后无法回复？
绝大多数是接口没配好：检查 Base URL 是否到 /v1、密钥是否有效、模型名是否拼写正确，可在“请求日志”里看具体报错。
安装提示“解析包失败 / 不兼容”？
本包最低 Android 8.0；极老的 x86 模拟器不适用。请确认设备是 ARM（32 位或兼容 32 位的 64 位）。
32 位包会不会更慢？
推理速度主要取决于模型服务端；本地原生库（PDF、分词等）均已为 armv7 重新编译，可正常运行。
