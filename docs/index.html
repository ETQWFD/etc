RikkaHub etc 2.0

开源项目 RikkaHub 的修改版 · 开发者 etc · 安卓聊天客户端

单个安装包内置 armeabi-v7a（32 位）、arm64-v8a（64 位）、x86_64（模拟器 / 虚拟机）三套原生库，安装时按设备架构自动选择，无需分别找包。需要 Android 8.0（API 26）及以上。

功能

  • 聊天：支持流式输出，模型服务商自行配置
  • 服务商：内置 OpenAI、DeepSeek、月之暗面、智谱、通义、Gemini、Claude、Ollama 等 30 家预设，填写 API 地址与密钥即可使用
  • 本地模型：内置 GGUF 聊天模型与绘图模型下载，支持 DeepSeek、Qwen、Llama 系列，下载后离线对话
  • Termux 终端：工作区终端采用 Termux 核心，无需 root
  • Angel 模式：授予无障碍权限后，可在聊天中下指令执行点击、输入、滚动等操作
  • 应用内更新：检查 GitHub Release，分块下载后跳转系统安装器
  • 语言：简体中文 / 繁体中文 / English 切换

安装

下载 Reai.apk 安装即可。安装包已包含三套架构的原生库，真机、模拟器、虚拟机均可用。应用未上架应用商店。
