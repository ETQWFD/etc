能做什么

多服务商切换

自定义 API 地址、密钥和模型列表，一套界面切换不同后端。

多模态输入

支持图片、文本、PDF、Docx 等内容一起发给模型。

中文全文搜索

内置 jieba 分词与拼音，聊天记录可按中文关键词检索。

文档解析

通过 MuPDF 在本地解析 PDF，32 位原生库已重新编译。

Markdown 渲染

代码高亮、表格、公式、Mermaid 图表都能正常显示。

深色模式

跟随系统外观，Material 风格界面。

安装说明

这个安装包只包含 armeabi-v7a（32 位 ARM）原生库，面向 32 位手机。 较新的 64 位手机一般也能兼容运行 32 位程序；如果你需要 64 位原生包，请使用 RikkaHub 官方版本。

下载后如果系统提示“未知来源”，在设置里允许当前浏览器安装应用即可。应用未上架应用商店，安装前可对照页面公布的 SHA-256 校验值核对文件。
